Notes
  • Un seul gabarit (en-tête, carte, bouton, pied) partagé par les deux mails, écrit avec React Email et rendu en HTML au démarrage de Strapi.
  • Pas d'image ni de police web : les clients mail les bloquent. Logo en texte sur fond rouge, titre Georgia, corps Arial.
  • Le lien est toujours écrit en clair sous le bouton : certains clients neutralisent les boutons.
  • Les mails ne connaissent pas la langue du lecteur (Strapi n'a pas cette information) : français d'abord, un bloc anglais court en pied. L'arrivée sur le site, elle, est dans la langue du lecteur.
  • Version texte générée depuis le même gabarit pour les clients sans HTML.
