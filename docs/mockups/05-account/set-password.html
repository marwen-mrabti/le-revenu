Carte « Mot de passe » d'un compte Google

Même page /account. La carte dépend d'une seule information : le compte a-t-il un mot de passe ?

1 · Compte Google sans mot de passe aujourd'hui : renvoi vers « Mot de passe oublié »

Mot de passe via Google

Vous vous connectez avec Google. Ajoutez un mot de passe pour pouvoir aussi vous connecter avec votre e-mail. Les deux fonctionneront.

Au moins 8 caractères.

Pas de champ « mot de passe actuel » : il n'y en a pas. Strapi n'accepte cette route que si le compte n'a aucun mot de passe.

Mot de passe via Google

✓ Mot de passe défini. Vous pouvez maintenant vous connecter avec Google ou avec votre e-mail.
Au moins 8 caractères.

Juste après : la carte devient le formulaire habituel de changement (la confirmation est sur la troisième colonne, comme aujourd'hui).
